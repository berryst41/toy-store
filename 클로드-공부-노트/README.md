# 📎 클로드 공부 노트

인스타그램·블로그에서 본 클로드(Claude) 관련 글을 핵심만 정리해서 모아두는 개인 공부 노트예요.

## 어떻게 쓰나요?

1. [노트 열기](https://berryst41.github.io/toy-store/클로드-공부-노트/)
2. 직접 글을 읽고 제목·요약·핵심 포인트·태그를 입력창에 적어 저장하거나,
3. **📸 캡처·PDF로 자동 정리** 칸에서 캡처 이미지나 PDF 파일을 여러 개 고르면 AI(Gemini, 무료)가 그 안의 핵심 키워드를 하나하나 뽑아서(예: "Remotion", "Playwright"), 키워드마다 따로 찾아보고 정리해서 노트 하나씩 저장해요. (실시간 웹 검색은 무료 등급에서 막혀 있을 수 있는데, 그럴 땐 AI가 아는 내용으로 대신 정리해요)
4. 또는 캡처 이미지나 복사한 글을 Claude 대화창에 붙여넣고 "이거 정리해서 클로드 공부 노트에 추가해줘"라고 말하면, Claude가 내용을 요약해서 바로 저장해 줘요.

저장된 노트는 카드로 쌓이고, 검색·태그로 다시 찾아볼 수 있어요. 여러 기기(폰·PC)에서 똑같이 보여요.

## 업데이트 기록
