## 🪀 진열장

| | 장난감 | 어떤 거예요? | 구경하기 |
|:---:|:---|:---|:---:|
| 📦 | *곧 첫 장난감이 들어와요!* | | |

<br>

## 🔍 이런 걸 만들어요

- 🎮 해 보고 싶었던 **게임**이나 놀잇감
- 💡 "이거 어떻게 되는 거지?" 싶어서 직접 **실험해 본 것**
- 🧪 완성이 아니어도 괜찮은 **시도와 연습**

> [!NOTE]
> 여기 있는 건 완성품이 아닐 수도 있어요. 만들다 말았거나, 고장 났거나, 엉뚱해도 그게 바로 장난감 가게의 매력이에요. 😊

<br>

## 🗂️ 진열 방법

장난감마다 폴더를 하나씩 만들어서 넣어요.

```
toy-store/
├── 장난감-이름/
│   ├── index.html    ← 열면 바로 구경할 수 있어요
│   └── README.md     ← 어떤 장난감인지 짧은 설명
└── README.md         ← 지금 보고 있는 진열장
```
