방탈출 예약 도우미 (크롬 확장 프로그램) 설치 방법

1. 이 압축 파일을 풀어 "extension" 폴더를 원하는 곳(예: 문서)에 둡니다. 폴더는 지우지 마세요.
   (예전 버전을 쓰고 계셨다면 예전 "extension" 폴더 안의 파일을 새 파일로 바꾼 뒤,
    chrome://extensions 에서 도우미 카드의 동그란 새로고침 단추를 한 번 누르면 됩니다.)
2. 크롬 주소창에 chrome://extensions 를 입력합니다.
3. 오른쪽 위 "개발자 모드"를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다"를 누르고 "extension" 폴더를 고릅니다.
5. 아래 사이트의 예약 화면을 열면 오른쪽 아래에 도우미 창이 나타납니다.
   (주황색 제목줄을 누르면 작게 접히고, 다시 누르면 펼쳐집니다.)

쓸 수 있는 사이트
- 키이스케이프 (keyescape.com) : 지점 → 테마 → 날짜 → 시간 → NEXT → 내 정보·필수 동의까지
- 판타스트릭 (fantastrick.co.kr/reserve) : 테마 → 날짜 → 시간 → 내 정보·필수 동의까지
    · 지점 칸은 없어요. 테마 칸에 "사자의 서"처럼 적어 주세요.
    · 예약은 일주일 뒤 날짜가 저녁 9시에 열려서 열리는 시각이 21:00:00으로 들어가요.
    · 도우미 창 [예약 비번]에 숫자 4자리를 적어 두면 예약 비밀번호 칸도 같이 채워요.
- 제로월드 (zeroworldkorea.com) : 지점 → 테마 → 날짜 → 시간까지
    · 제로월드는 이름·전화번호 칸에 붙여넣기와 크롬 자동완성을 일부러 막아 두어서, 내 정보는 채우지 않아요.
      대신 시간을 고르면 이름 칸에 커서를 놓아 두니 바로 적으면 돼요.
    · 지점별로 열리는 시각을 찾지 못해서 [열리는 시각]은 직접 적어 주세요.
- 비트포비아 던전 (xdungeon.net) : 지점·날짜 → 그 테마의 시간 → 내 정보·필수 동의까지
    · 같은 시간이 여러 테마에 있어서, 시간까지 고르려면 테마 이름을 꼭 적어 주세요. (예: 사라진 보물)
    · 지점을 고르면 열리는 시각이 저절로 들어가요. (홍대던전 13시 ~ 서면던전 레드 21시)
- doloescape.co.kr, thefrank.co.kr : 제로월드와 같은 예약 화면이라 테마 → 날짜 → 시간 → 내 정보까지 해 봐요.
    · 예약 화면(home.php?go=rev.make) 주소에서 쓰세요. 지점이 여럿이면 그 지점 화면을 먼저 열어 두세요.
    · 열리는 시각은 직접 적어 주세요.
- dpsnnn.com (reserve 화면) : 테마 → 날짜 → 시간 → 내 정보를 일반 방식으로 찾아 봐요.
- 이 세 곳은 사이트가 제 작업 공간의 접속을 막아서 실제 화면을 보지 못했어요.
  칸을 못 찾거나 멈추면 그 화면을 캡처해서 Claude에게 보내 주세요.

쓰는 순서
① 예약이 열리기 몇 분 전에 예약 화면을 엽니다. 도우미 창 맨 위 큰 시계가 "그 사이트의 서버 시간"입니다.
② [지점]을 고르면 열리는 시각이 저절로 들어갑니다. (직접 10:00:00 처럼 적어도 됩니다.)
   [여유(초)]는 정각보다 몇 초 늦게 새로고침할지입니다. 기본 0.3초. 너무 일찍 새로고침되면 조금 늘려 보세요.
③ [이 시각에 새로고침 예약]을 누릅니다. 시간이 되면 이 탭을 딱 한 번 새로고침합니다.
   - 탭을 화면 앞에 띄워 두세요. 다른 탭을 보고 있으면 크롬이 타이머를 늦춰서 1초쯤 늦을 수 있어요.
   - 컴퓨터가 절전 모드로 들어가지 않게 해 두세요.
④ 지점·테마·날짜·시간까지 저절로 고르게 하려면 도우미 창에 적어 두세요.
   - 지점: 목록에서 고르기 / 테마: 화면 글자와 똑같이 (예: 머니머니패키지)
   - 날짜: 10/31 처럼 / 시간: 14:30 처럼
   - "이 지점·테마·날짜·시간 저절로 고르기"를 켭니다.
   사이트마다 따로 기억하니까, 사이트별로 한 번씩 적어 두면 됩니다.
   새로고침되면 지점 → 테마 → 날짜 → 시간을 차례로 누르고, 다음 단계(NEXT)가 있으면 누른 뒤 내 정보를 채웁니다.
   그 시간이 "마감"이거나 날짜가 아직 안 열렸으면 멈추고 알려 줍니다. 날짜·시간을 비워 두면 지점·테마까지만 고릅니다.
⑤ 직접 고를 때는 입력칸이 보이면 [내 정보 채우기]를 누릅니다.
   ("입력칸이 나타나면 자동으로 채우기"를 켜 두면 저절로 채웁니다.)
   "필수 동의 칸도 체크하기"를 켜 두면 개인정보·결제 주의사항 동의도 체크합니다. (마케팅 동의는 체크하지 않아요.)
   동의 내용은 미리 한 번 (보기)를 눌러 읽어 두세요.
⑥ "로봇이 아닙니다", 그림 글자(자동등록방지)는 직접 입력합니다.
   내용을 확인하고 예약(신청) 버튼도 직접 누릅니다. 입금 기한 안에 입금해야 예약이 끝납니다.

알아 두세요
- 내 정보(이름·전화번호·인원)는 이 컴퓨터의 크롬 안에만 저장됩니다. 어디로도 보내지 않습니다.
- 서버 시간을 맞출 때 사이트에 아주 작은 요청을 8번 보내고, 정해 둔 시각 20초 전에 8번 더 보냅니다. 사이트에 부담을 주지 않는 양입니다.
- 키이스케이프는 대리 예약, 예약 양도·판매를 금지합니다. 다른 사이트도 본인 예약에만 쓰세요.
- 칸을 못 찾으면 그 화면을 캡처해서 Claude에게 보내 주세요. 사이트에 맞게 고쳐 드릴게요.
