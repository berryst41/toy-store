# 🍓 캘린더 다리 (안드로이드 앱)

폰에 있는 **모든 캘린더(삼성 계정 · 구글 · 내 폰)** 일정을 읽어서 **AI 딸기**로 보내 주는 작은 앱이에요.
AI 딸기(웹 앱)는 폰 안의 삼성 캘린더를 직접 읽을 수 없어서, 이 앱이 다리 역할을 해요.

[⬇️ 캘린더 다리 받기 v0.3.0](https://github.com/berryst41/toy-store/releases/download/calendar-bridge/calendar-bridge.apk)

지금 버전: **v0.3.0** (2026-11-22)

- 15분마다 한 번, 그리고 삼성 캘린더에서 일정을 넣거나 고치면 1~2분 안에 보내요.
- **AI 딸기에서 일정 넣기·고치기·지우기**도 해요. AI 딸기에서 [허락]을 누른 것만 해요.
  - 폰의 AI 딸기에서 허락하면 캘린더 다리가 잠깐 깨어나서 **바로** 넣어요(화면이 한 번 깜빡여요).
  - PC에서 허락하면 **15분 안에** 넣어요. 급하면 폰에서 캘린더 다리 앱을 열기만 하면 바로 넣어요(앱 화면이 켜져 있는 동안은 5초마다 확인해요).
  - 캘린더를 말하지 않으면 AI 딸기 ⚙️ → 📱 폰 캘린더의 **"새 일정을 넣을 기본 캘린더"**(처음엔 공유용)에 들어가요.
  - 반복 일정은 전체가 바뀔 수 있어서 고치기·지우기를 막아 뒀어요. 폰 삼성 캘린더에서 직접 해 주세요.
- **보낼 캘린더를 골라요.** 앱 화면 아래 "📚 AI 딸기로 보낼 캘린더"에서 필요 없는 캘린더의 체크를 끄면 그 일정은 안 보내요.
- 어제부터 60일 뒤까지의 일정을 보내요. 반복 일정도 날짜마다 펼쳐서 보내요.
- **읽기만 해요.** 폰 캘린더의 일정을 넣거나 고치거나 지우지 않아요.
- 구글 계정으로 이미 AI 딸기에 연결한 캘린더와 겹치는 일정은 AI 딸기에서 **한 번만** 보여요.
- 안드로이드 폰 전용이에요. Play 스토어에는 없고, 위 주소에서 직접 받아 설치해요(무료).

---

## 1. 설치하기 (처음 한 번, 5분)

갤럭시 S26 기준이에요. 메뉴 이름은 폰마다 조금 다를 수 있어요.

1. **폰에서** AI 딸기를 열고 ⚙️ → **📱 폰 캘린더** → **[⬇️ 캘린더 다리 앱 받기]** 를 눌러요.
   (또는 위의 "캘린더 다리 받기" 링크를 폰에서 눌러요)
2. "파일을 다운로드할까요?"가 나오면 **[다운로드]**. 다 받아지면 아래 알림이나 화면의 **[열기]** 를 눌러요.
3. **"보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없어요"** 가 나오면
   → **[설정]** → **"이 출처 허용"** 을 켜고 → 뒤로 가기 → **[설치]**.
4. **"자동 차단이 켜져 있어 설치할 수 없어요"** 가 나오면 (갤럭시의 '자동 차단' 기능)
   → 설정 → **보안 및 개인정보 보호** → **자동 차단** → 잠깐 **끄기** → 다시 2번부터.
   설치가 끝나면 자동 차단을 **다시 켜도 돼요** (이미 설치된 앱은 그대로 돼요).
5. **Play 프로텍트**가 "안전하지 않은 앱" 또는 "앱 검사" 창을 띄우면
   → **[세부정보 더보기]** → **[무시하고 설치]** (또는 [앱 검사] 뒤 [설치]).
   우리가 직접 만든 앱이라 Play 스토어 기록이 없어서 뜨는 경고예요.

## 2. 처음 켜서 설정하기

앱 서랍에서 **🍓 캘린더 다리** 를 열어요.

1. **로그인:** AI 딸기 ⚙️에서 로그인할 때 쓰는 **같은 이메일과 비밀번호**를 넣고 [로그인].
   비밀번호는 폰에 저장하지 않아요(로그인 뒤 받은 '이어 쓰기 열쇠'만 폰 안에 둬요).
2. **캘린더 권한:** "캘린더에 액세스하도록 허용할까요?" → **[허용]**.
   - 실수로 거부했다면: 앱의 [캘린더 권한 허용하기] → (설정 화면이 열리면) **권한 → 캘린더 → 허용**.
3. **배터리 제한 풀기:** 앱의 [배터리 제한 풀기] → "백그라운드에서 항상 실행하도록 허용할까요?" → **[허용]**.
4. 화면에 **"✅ 캘린더 ○개 · 일정 ○개 보냄"** 이 나오면 끝이에요.
   AI 딸기 ⚙️ → 📱 폰 캘린더에도 "✅ (폰 이름) · 방금 보냄"이 보여요.

## 3. 앱이 잠들지 않게 하기 (갤럭시는 꼭!)

갤럭시는 배터리를 아끼려고 잘 안 여는 앱을 재워요. 재우면 일정이 늦게 가요. 아래 두 가지를 해 주세요.

1. **설정 → 애플리케이션 → 🍓 캘린더 다리 → 배터리 → "제한 없음"** 고르기.
   (앱 안의 [이 앱 설정 열기] 버튼을 누르면 바로 이 화면 근처로 가요)
2. **설정 → 배터리 → 백그라운드 사용 제한** 에서
   - "절전 상태 앱", "딥 슬립 앱" 목록에 캘린더 다리가 **없어야** 해요. 있으면 눌러서 빼요.
   - 가능하면 **"절전 예외 앱"** 에 캘린더 다리를 더해요.

> 확인 방법: 하루쯤 지나 AI 딸기 ⚙️ → 📱 폰 캘린더에서 "⚠️ 3시간 넘게 소식이 없어요"가 뜨면 위 설정을 다시 봐 주세요.
> 그래도 안 되면 캘린더 다리 앱을 한 번 열기만 해도 바로 보내요.

## 4. 자주 묻는 것

- **일정을 AI 딸기에서 넣거나 고치거나 지울 수 있나요?** 네(v0.3.0~). "내일 3시 학년 회의 넣어 줘", "학년 회의 4시로 바꿔 줘", "학년 회의 지워 줘"처럼 말하고 [허락]을 누르면 돼요. 📅 일정 탭의 📱 일정 옆 ✕로도 지울 수 있어요.
- **새 일정은 어느 캘린더에 들어가나요?** 말하지 않으면 기본 캘린더(처음엔 공유용)예요. "공유용-민규에 넣어 줘"처럼 말하거나, 허락 카드에서 캘린더를 바꿀 수 있어요. 기본은 AI 딸기 ⚙️ → 📱 폰 캘린더에서 바꿔요.
- **업데이트한 뒤 할 일:** 캘린더 다리를 한 번 열어 [캘린더 권한 허용하기] → 쓰기도 허용해 주세요.
- **필요한 캘린더만 보내려면?** 앱을 열고 "📚 AI 딸기로 보낼 캘린더"에서 필요 없는 것의 체크를 꺼요. 2초 뒤 저절로 다시 보내고, AI 딸기에서도 그 일정이 사라져요. 다시 켜면 다시 보내요.
- **숨긴 캘린더는요?** 삼성 캘린더에서 체크를 꺼 둔(숨긴) 캘린더는 AI 딸기에도 안 보여요.
- **폰을 바꾸면?** 새 폰에 다시 설치하고 로그인하면 돼요.
- **그만 쓰려면?** 앱에서 [로그아웃]을 누르면 보내기를 멈춰요. 앱을 지워도 돼요.
- **업데이트는?** 새 버전이 나오면 같은 주소에서 다시 받아 설치하면 그대로 덮어써져요(다시 로그인 안 해도 돼요).

### 만드는 사람용 메모
- 코드: `app/src/main/java/app/berryst/calbridge/` (안드로이드 기본 기능만, 라이브러리 없음). 패키지 `app.berryst.calbridge`.
- 서버: Supabase `couple` 프로젝트의 표 `ai_phone_cal` (기기마다 한 줄: calendars, events, synced_at, write_cal=기본 넣을 캘린더). 잠금 규칙 = 주인만.
- 쓰기 쪽지: 표 `ai_phone_cmd`(op add/update/delete, cal, event_id, data, status wait→run→done/fail, result). `Cmd.java`가 처리. 깨우기 주소 `calbridge://run`(`WakeActivity`, 투명).
- 빌드: `.github/workflows/calendar-bridge.yml` — main에 들어오면 릴리스 `calendar-bridge`에 `calendar-bridge.apk`를 올려요.
- 서명 열쇠: GitHub Secrets `CALBRIDGE_KEYSTORE`(열쇠 파일 base64). 열쇠를 바꾸면 기존 앱 위에 업데이트가 안 돼요.
