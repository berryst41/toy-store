# 🖥️ AI 비서 PC 일꾼

앱(폰·PC)에서 맡긴 일을 **이 PC에서 따로 연 브라우저 창**으로 대신 해 줘요.
(웹 앱은 보안 때문에 다른 사이트를 대신 누를 수 없어서, PC에서 도는 작은 프로그램이 대신 해요.)

- 👀 **빈자리 지켜보기** — 페이지를 정한 간격(30초~)으로 새로고침하다가 "잔여"·"예약 가능" 같은 글자가 **나타나거나**, "매진"이 **사라지면** 폰으로 알림. 그 창은 열어 둬서 바로 직접 할 수 있어요.
- 🖱️ **대신 하기** — AI가 화면을 보고 하나씩 눌러요. **예약·결제·신청·보내기·삭제처럼 되돌리기 어려운 버튼 앞에서는 멈추고** 앱에 화면 사진과 함께 ✋ 확인 카드를 띄워요. [허락]해야 눌러요.
  - 끝나면 화면에 "예약이 완료되었습니다" 같은 **확인 글자가 진짜 있는지** 다시 보고 알려 줘요.
  - 비밀번호·카드번호·인증번호는 **절대 넣지 않아요.** 로그인·본인인증이 필요하면 멈추고 알려 줘요 → PC의 일꾼 창에서 직접 하고 [허락]을 누르면 이어서 해요.

- 📨 **쿨메신저 비서 맞추기 (v0.6)** — 이 PC에 쿨메신저 비서가 깔려 있으면, 정리된 항목(할 일·적을 것·기억할 것)만 20초마다 앱으로 보내요. **쪽지 원문과 쿨메신저 비서의 키는 보내지 않아요.** 앱에서 체크하면 쿨메신저 비서 창에도 체크되고, 반대도 돼요. 쿨메신저 비서가 없는 PC(예: 집 PC)에서는 이 일은 그냥 건너뛰어요.

## 처음 한 번
1. 이 폴더(`pc-일꾼`)를 PC에 받아요. (GitHub toy-store → `AI-비서/pc-일꾼` 폴더, 또는 앱 ⚙️의 받기 링크)
2. **`일꾼-켜기.bat`** 더블클릭. (Node.js가 없으면 설치 사이트가 열려요 → 설치 후 다시 더블클릭)
3. 앱 ⚙️ 설정 → 🖥️ PC 일꾼 → **[연결 코드 만들기]** → 나온 8글자를 검은 창에 입력.
4. 일꾼이 여는 브라우저 창에서, 자주 쓸 사이트(네이버·쿠팡·예약 사이트 등)에 **한 번 로그인**해 두세요. 로그인은 그 창에 계속 남아요(내 PC 안에만).

## PC를 켤 때 저절로 켜기 (작업 표시줄에 안 뜨게)
- 위 "처음 한 번"(연결 코드까지)을 끝낸 뒤 **`PC-켤때-자동켜기.bat`** 을 한 번 더블클릭하세요. 이제 PC를 켜면 일꾼이 **검은 창 없이** 숨어서 켜져요. 작업 표시줄에도 안 보여요.
- 켜져 있는지는 폰 앱 ⚙️ → 🖥️ PC 일꾼에서 🟢로 보여요. 맡긴 일(지켜보기·대신 하기)이 있을 때만 브라우저 창이 열려요.
- 끄려면 **`자동켜기-끄기.bat`** — 자동 켜기를 끄고, 숨어서 돌던 일꾼도 꺼요.
- 이 폴더를 옮기거나 지우면 자동 켜기가 안 돼요. 옮겼다면 `PC-켤때-자동켜기.bat`을 다시 더블클릭하세요.
- 숨어서 도는 동안 남긴 글: `%LOCALAPPDATA%AI비서일꾼일꾼-기록.txt`
- 일꾼은 한 PC에 하나만 켜져요. 숨은 일꾼이 도는 중에 `일꾼-켜기.bat`을 누르면 "이미 켜져 있어요"라고 알려 줘요.

## 다음부터
`일꾼-켜기.bat` 더블클릭만 하면 돼요. 검은 창을 닫으면 일꾼도 꺼져요. 앱 ⚙️에서 🖥️ 일꾼이 켜져 있는지 보여요.

## 알아 두기
- PC가 켜져 있고 일꾼 창이 떠 있어야 일해요.
- 자동화를 막는 사이트(예: 일부 기차·공연 예매)는 안 될 수 있어요. 그럴 땐 "못 했어요"라고 알려 줘요.
- 저장 위치: `%LOCALAPPDATA%\AI비서일꾼` (로그인 정보·브라우저 기록). 지우면 연결도 끊겨요.
