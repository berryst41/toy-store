# 🤖 AI 비서

**일정·할 일 관리 + 쿨메신저 할 일 + 무엇이든 질문**을 한 곳에서 해 주는 AI 비서예요. 폰과 PC 모두에서 써요.

주소: https://berryst41.github.io/toy-store/ai (짧은 주소, 원래 주소 https://berryst41.github.io/toy-store/AI-%EB%B9%84%EC%84%9C/ 로 넘어가요)

지금 버전: **v0.23.1** (2026-11-26)

## 할 수 있는 것
- 💬 **말로 시키기:** "내일 3시 학년회의 넣어줘", "금요일까지 출장 신청서 할 일에 넣어줘", "우리 반 24명이라고 기억해" → 일정·할 일·기억에 알아서 들어가요. 🎤 버튼으로 말해도 돼요.
- ☀️ **오늘 브리핑 / 이번 주:** 일정과 할 일을 정리하고 먼저 할 일 순서를 추천해요.
- 📧 **메일 정리:** 메일 탭을 열면 답장할 것·할 일·일정·알림·광고로 나누고 요약해 줘요. 지메일에도 라벨을 붙이고 광고는 보관함으로 옮겨요(지우지 않아요).
- 🙋 **그 밖의 질문:** 궁금한 것 무엇이든.
- 📅 **일정·할 일 탭 / 📒 기억 탭:** 직접 넣고 지우고 체크할 수도 있어요.

## v0.13에서 새로 생긴 것 — 🚌 고속버스 빈자리 알림
- 폰에서 말로: "25일 서울에서 대전 저녁 5~7시 버스 2자리 나면 알려 줘" (또는 🖥️ 일꾼 탭 → 🚌 고속버스 빈자리 알림)
- PC 일꾼이 kobus(고속버스통합예매)에서 5분마다(2·10분도 고를 수 있어요) 그 시간대 남은 자리를 보고, 생기면 **폰으로 알림**을 보내요. 예매는 직접 해요(티머니GO 앱이나 kobus).
- AI를 쓰지 않아서 AI 사용량이 줄지 않아요. "서울"처럼 말하면 서울경부·센트럴시티를 같이 봐요. 시외버스·기차는 안 돼요.
- PC 일꾼도 새 zip(v0.8.0)으로 바꿔야 해요.

## v0.12에서 새로 생긴 것 — 📅 자동 예약
- 🖥️ 일꾼 탭 → **📅 예약 맡기기**(또는 대화로 "이 링크로 25일 저녁 6~8시 치과 예약해 줘"). 네이버 예약(병원·미용실·식당), 방탈출, 고속·시외버스에 맞춘 요령이 들어 있어요.
  - **✋ 확정 전 물어보기(추천):** 일꾼이 날짜·시간·인원을 다 고르고, 마지막 "예약하기" 앞에서 화면 사진과 함께 허락을 받아요.
  - **🤖 끝까지 자동:** 돈이 안 드는 예약은 묻지 않고 확정까지 해요. 결제·예약금이 나오면 **언제나** 멈추고 물어봐요.
  - **⏰ 정각 예약:** "매달 1일 9시에 열리는 예약"처럼 열리는 시각을 정하면, 10분 전에 창을 열어 두고 사이트 시계로 열린 걸 확인해 몇 초 뒤 시작해요. 마지막 확정은 꼭 물어봐요.
  - **🔁 자리 없으면 다시:** 원하는 시간대에 자리가 없으면 30분·1시간마다 다시 봐요(10번까지). 다른 날짜는 마음대로 고르지 않아요.
  - **🛡️ 계정 보호:** 대부분 사이트 약관이 자동 프로그램을 막아서, 짧은 간격 반복·정각 경쟁은 하지 않아요. **코레일·SRT는 매크로 예매 금지라 아예 안 해요.**
  - **📅 캘린더 자동 등록:** 예약 완료 글자를 화면에서 확인하면 폰 기본 캘린더(공유용)에 넣어요.
  - 네이버는 로그인이 안 돼 있으면 먼저 "일꾼 창에서 로그인해 주세요" 카드를 띄워요.
  - PC 일꾼도 새 zip(v0.7.0)으로 바꿔야 해요.

## v0.8에서 새로 생긴 것
- 📱 **삼성 캘린더 일정도 함께:** 갤럭시 폰에 [🍓 캘린더 다리](calendar-bridge/README.md) 앱([⬇️ 받기 v0.1.0](https://github.com/berryst41/toy-store/releases/download/calendar-bridge/calendar-bridge.apk))을 깔면, 폰의 모든 캘린더(삼성 계정·구글·내 폰) 일정이 📅 일정 탭·AI 대화·아침 브리핑에 같이 나와요. 구글에 있는 일정과 겹치면 한 번만 보여요. 폰 일정은 읽기만 해요.

## v0.5에서 새로 생긴 것
- 🖥️ **PC 일꾼:** 웹 앱은 보안 때문에 다른 사이트를 대신 누를 수 없어서, PC에서 도는 작은 프로그램([pc-일꾼](pc-일꾼/README.md), [⬇️ zip v0.10.1](pc-일꾼.zip))이 **따로 연 브라우저 창**에서 대신 해요.
  - 👀 **빈자리 지켜보기:** 주소와 찾을 글자("잔여", "예약 가능")를 주면 30초~5분마다 새로고침하다가 나타나면(또는 "매진"이 사라지면) 폰 알림.
  - 🖱️ **대신 하기:** AI가 화면을 보고 하나씩 눌러요. 예약·결제·신청·보내기·삭제 버튼 앞에서는 멈추고 화면 사진과 함께 ✋ 허락을 받아요. 끝나면 화면에 확인 글자가 진짜 있는지 다시 봐요. 비밀번호·카드번호는 넣지 않아요(로그인은 일꾼 창에서 직접).
  - 대화로도 맡길 수 있어요: "이 링크 빈자리 나면 알려 줘", "이 사이트에서 24일 7시 2명 예약해 줘".
  - 새 탭 🖥️ 일꾼: 맡긴 일·진행 상황·화면 사진·허락 버튼·멈추기.

## v0.4에서 새로 생긴 것
- ☀️ **아침 브리핑 알림:** ⚙️에서 시각을 정하고 [🔔 이 기기에서 알림 받기]를 누르면 매일 그 시각에 오늘 일정·마감·안 읽은 메일·💡 제안이 폰·PC 알림으로 와요(AI 사용량 안 씀). 알림을 누르면 앱이 열리고 자세한 브리핑을 바로 해 줘요. [📨 지금 시험으로 받아 보기]도 있어요.
- 💡 **먼저 제안하기:** 첫 화면에 지금 상황에 맞는 제안 버튼이 떠요(마감 지난 할 일 정리, 오늘 마감, 내일 준비, 안 읽은 메일 요약 등). 누르면 바로 도와줘요.
- 🧠 **기억 키우기:** 대화하다 "우리 반은 24명이야"처럼 오래 쓸 정보를 말하면 비서가 알아서 기억하고, 바뀌면 고쳐요. 같은 건 두 번 안 넣어요. 기억 탭에서 눌러서 고치거나 지울 수 있어요.
- ✏️ 할 일 마감 미루기·이름 고치기도 말로 돼요.

## v0.3에서 새로 생긴 것
- 🔗 **구글 계정 여러 개 연결:** ⚙️에서 계정마다 이름표·색·허락 범위(캘린더만 / +메일 읽기 / +메일 보내기)를 골라 연결해요. ⭐ 기본 계정, 연결 끊기도 돼요. (처음 한 번 [구글연결-설정.md](구글연결-설정.md) 필요)
- 📅 **캘린더 합쳐 보기:** 모든 구글 캘린더 일정이 색깔별로 한 화면에. 일정 넣을 곳(AI 비서 / 각 구글 계정)도 고를 수 있어요.
- 📬 **메일 탭:** 모든 계정의 최근 메일을 모아 보고, 누르면 본문 → 🤖 요약 / ✍️ 답장 쓰기.
- ✋ **구글 일도 허락 먼저:** 구글 캘린더에 넣기·지우기, 메일 보내기는 확인 카드에서 **계정을 고르고 메일 내용을 본 뒤** [허락]해야 실행돼요. 실행 뒤 캘린더·보낸편지함을 다시 읽어 ✔️ 확인해요.

## v0.2에서 새로 생긴 것
- ☁️ **폰·PC 자동 동기화:** ⚙️ 설정에서 이메일·비밀번호로 로그인하면 일정·할 일·기억·대화가 저절로 맞춰져요. 위쪽 ☁️ 표시로 상태를 볼 수 있어요. 처음 가입한 한 사람만 쓸 수 있게 잠겨 있어요.
- 🔋 **오늘 AI 사용량:** 위쪽에 "오늘 쓴 횟수 / 하루 한도"가 늘 보여요(폰·PC 합계). 한도에 걸리면 ⛔로 바뀌어요.
- ✋ **확인 카드:** AI가 무언가를 지우려 하면 바로 지우지 않고 [허락] 버튼을 먼저 보여 줘요.
- ✔️ **진짜 됐는지 확인:** 넣거나 지운 뒤 서버를 다시 읽어서 정말 저장됐는지 확인하고 표시해 줘요.

## 쓰는 방법
1. **처음 한 번:** 위 주소를 폰 크롬(⋮ → 홈 화면에 추가)과 PC 크롬(주소창 오른쪽 설치 버튼)으로 열어요.
2. ⚙️ 설정에 무료 AI 키를 넣어요. (aistudio.google.com/apikey → 구글 로그인 → "Create API key")
3. ⚙️ 설정의 **내 정보**에 "초등 5학년 담임, 정보 업무" 같은 걸 적어 두면 더 잘 맞춰 대답해요.

## 알아 두기
- 로그인하면 일정·할 일·기억·대화가 서버(Supabase)에 저장돼 폰·PC가 맞춰져요. 로그인하지 않으면 그 기기 안에만 있어요. AI 키는 기기마다 따로 넣어요.
- AI에게 물어볼 때만 글과 붙인 파일이 구글 Gemini로 보내져요. 학생 개인정보는 되도록 이름을 빼고 써 주세요.
- 무료 AI는 1분에 여러 번 연달아 쓰면 잠깐 막힐 수 있어요. 1분 뒤 다시 하면 돼요.
- 업데이트: 코드를 고쳐 올리면 다시 설치하지 않아도 다음에 열 때 바뀌어요.
