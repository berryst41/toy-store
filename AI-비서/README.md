# 🤖 AI 비서

**일정·할 일 관리 + 학교 업무 글쓰기 + 무엇이든 질문**을 한 곳에서 해 주는 AI 비서예요. 폰과 PC 모두에서 써요.

주소: https://berryst41.github.io/toy-store/AI-%EB%B9%84%EC%84%9C/

지금 버전: **v0.3.0** (2026-11-20)

## 할 수 있는 것
- 💬 **말로 시키기:** "내일 3시 학년회의 넣어줘", "금요일까지 출장 신청서 할 일에 넣어줘", "우리 반 24명이라고 기억해" → 일정·할 일·기억에 알아서 들어가요. 🎤 버튼으로 말해도 돼요.
- ☀️ **오늘 브리핑 / 이번 주:** 일정과 할 일을 정리하고 먼저 할 일 순서를 추천해요.
- 🏫 **학교 업무:** 📄 공문 요약(📎로 PDF·사진 붙이기, 마감일은 할 일로), 📝 기안문, 💌 가정통신문, 📱 학부모 문자, 🧒 생기부 문구. 답 아래 📋 복사 버튼으로 바로 붙여넣기.
- 🙋 **그 밖의 질문:** 저녁 메뉴, 궁금한 것 무엇이든.
- 📅 **일정·할 일 탭 / 📒 기억 탭:** 직접 넣고 지우고 체크할 수도 있어요.

## v0.3에서 새로 생긴 것
- 🔗 **구글 계정 여러 개 연결:** ⚙️에서 계정마다 이름표·색·허락 범위(캘린더만 / +메일 읽기 / +메일 보내기)를 골라 연결해요. ⭐ 기본 계정, 연결 끊기도 돼요. (처음 한 번 [구글연결-설정.md](구글연결-설정.md) 필요)
- 📅 **캘린더 합쳐 보기:** 모든 구글 캘린더 일정이 색깔별로 한 화면에. 일정 넣을 곳(AI 비서 / 각 구글 계정)도 고를 수 있어요.
- 📬 **메일 탭:** 모든 계정의 최근 메일을 모아 보고, 누르면 본문 → 🤖 요약 / ✍️ 답장 쓰기.
- ✋ **구글 일도 허락 먼저:** 구글 캘린더에 넣기·지우기, 메일 보내기는 확인 카드에서 **계정을 고르고 메일 내용을 본 뒤** [허락]해야 실행돼요. 실행 뒤 캘린더·보낸편지함을 다시 읽어 ✔️ 확인해요.

## v0.2에서 새로 생긴 것
- ☁️ **폰·PC 자동 동기화:** ⚙️ 설정에서 이메일·비밀번호로 로그인하면 일정·할 일·기억·대화가 저절로 맞춰져요. 위쪽 ☁️ 표시로 상태를 볼 수 있어요. 처음 가입한 한 사람만 쓸 수 있게 잠겨 있어요.
- 🔋 **오늘 AI 사용량:** 위쪽에 "오늘 쓴 횟수 / 하루 한도"가 늘 보여요(폰·PC 합계). 한도에 걸리면 ⛔로 바뀌어요.
- ✋ **확인 카드:** AI가 무언가를 지우려 하면 바로 지우지 않고 [허락] 버튼을 먼저 보여 줘요.
- ✔️ **진짜 됐는지 확인:** 넣거나 지운 뒤 서버를 다시 읽어서 정말 저장됐는지 확인하고 표시해 줘요.

## 쓰는 방법
1. **처음 한 번:** 위 주소를 폰 크롬(⋮ → 홈 화면에 추가)과 PC 크롬(주소창 오른쪽 설치 버튼)으로 열어요.
2. ⚙️ 설정에 무료 AI 키를 넣어요. (aistudio.google.com/apikey → 구글 로그인 → "Create API key")
3. ⚙️ 설정의 **내 정보**에 "초등 5학년 담임, 정보 업무" 같은 걸 적어 두면 더 잘 맞춰 대답해요.

## 알아 두기
- 로그인하면 일정·할 일·기억·대화가 서버(Supabase)에 저장돼 폰·PC가 맞춰져요. 로그인하지 않으면 그 기기 안에만 있어요. AI 키는 기기마다 따로 넣어요.
- AI에게 물어볼 때만 글과 붙인 파일이 구글 Gemini로 보내져요. 학생 개인정보는 되도록 이름을 빼고 써 주세요.
- 무료 AI는 1분에 여러 번 연달아 쓰면 잠깐 막힐 수 있어요. 1분 뒤 다시 하면 돼요.
- 업데이트: 코드를 고쳐 올리면 다시 설치하지 않아도 다음에 열 때 바뀌어요.
