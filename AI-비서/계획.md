# 🤖 AI 비서 만들기 계획 (피클 같은 비서)

정한 날: 2026-11-20 · 이 계획은 클로드 데스크톱 "AI 비서 만들기" 프로젝트와 PC Claude Code가 같이 봐요.

## 1. 목표
"말로 시키면 진짜로 해 주는" 비서. 폰·PC 둘 다에서 써요.

| 넣을 것 | 안 넣을 것 |
|---|---|
| 일정(구글 캘린더) · 메일(지메일) — **구글 계정 여러 개 모두 연결** · 기억 · 먼저 제안하기 | ❌ 전화 대행 |
| 예약 · 쇼핑(최저가 찾기, 장바구니) | ❌ 카드 번호 보관 / AI 혼자 결제 |
| 대신 눌러 주기 · 빈자리 지켜보다 알려 주기 · 대신 예약 | |
| 학교 업무 글쓰기 · 무엇이든 질문 (v0.1에 있음) | |

## 2. 꼭 지킬 약속 (처음부터 넣어요)
1. **허락 먼저:** 누르기·예약·결제·메일 보내기·일정 지우기 전에는 반드시 **확인 카드**를 띄워요. 카드에는 무엇을 할지, 화면 사진, 금액을 보여 줘요. 사용자가 [허락]을 눌러야만 실행해요.
2. **했다는 말 대신 확인:** 실행한 뒤에 예약 내역이나 장바구니 화면을 **다시 열어서** 실제로 됐는지 보고, 그 화면 사진을 증거로 남겨요. 확인이 안 되면 "됐는지 모르겠어요"라고 솔직하게 말해요.
3. **남은 사용량 보이기:** 오늘 AI를 몇 번 썼는지, 무료 한도까지 얼마나 남았는지 화면 위쪽에 항상 보여 줘요.
4. **시키지 않은 일은 하지 않기:** 범위가 애매하면(가게가 두 곳 등) 먼저 물어봐요.
5. **결제는 마지막 버튼을 사람이 눌러요:** 결제 화면까지만 가고, 결제 버튼은 허락받은 뒤에 누르거나 사용자가 직접 눌러요.

## 3. 로그인 정보 보관은 어떻게? (위험한가요?)
**비밀번호를 우리가 서버에 모아 두는 건 위험해요.** 피클은 보안 전문가들이 특수 금고 서버를 쓰는데도 걱정하는 말이 나와요. 우리 서버가 털리면 모든 비밀번호가 한 번에 나가요.

그래서 이렇게 해요.
- **비밀번호를 저장하지 않아요.** 대신 **PC 크롬에 이미 로그인된 상태를 그대로 빌려 써요.** 사용자가 PC에서 네이버·쿠팡 등에 한 번 로그인해 두면, PC 일꾼이 그 크롬으로 작업해요. 로그인 정보는 그 PC 밖으로 나가지 않아요.
- 로그인이 풀리면 비서가 "PC에서 ○○ 다시 로그인해 주세요"라고 알려 줘요.
- 본인인증·보안문자·QR 로그인은 사람이 해요. 피클도 똑같이 해요.
- 꼭 저장해야 하는 비밀번호가 생기면 **그 PC 안에만**, 윈도우 암호화(DPAPI)로 잠가서 둬요. 서버와 GitHub에는 절대 올리지 않아요.
- **카드 번호는 어디에도 저장하지 않아요.** 사이트에 이미 등록된 간편결제를 쓰고, 결제는 허락을 받은 뒤에만 해요.

## 4. 어떻게 생겼나 (세 덩어리)
```
 [📱 폰 앱 / 💻 PC 앱]  ←→  [☁️ 서버]  ←→  [🖥️ PC 일꾼]
  대화·확인 카드·알림        기억·동기화·구글 연결      진짜 크롬으로 누르기
  (지금 있는 PWA)          아침 브리핑·작업 줄 세우기   빈자리 감시·예약
```
- **앱:** 지금 v0.1 PWA를 키워요(GitHub Pages).
- **서버:** Vercel(이미 씀) + Supabase(무료 데이터베이스).
  - 데이터 저장 → 폰·PC 자동 동기화
  - 구글 로그인, 구글 캘린더·지메일 연결
  - 폰 알림(웹 푸시), 매일 아침 브리핑
  - PC 일꾼에게 일 넘기기(작업 목록 표)
- **PC 일꾼:** 학교·집 PC에서 도는 작은 프로그램이에요(Playwright, 버스 취소표 알리미 경험 재활용).
  - 서버의 작업 목록을 보고 일해요.
  - 허락이 필요하면 멈추고 폰으로 확인 카드를 보내요.
  - PC가 꺼져 있으면 못 해요 → 원격 켜기(WOL) 설정과 이어져요.

## 4-1. 구글 계정 여러 개 연결하기
- **앱 로그인은 대표 계정 하나로 해요.** ⚙️ 설정의 "연결된 구글 계정"에서 [+ 계정 더하기]를 눌러 몇 개든 더 붙여요. 계정마다 따로 허락을 받아요.
- 계정마다 **이름표와 색깔**을 붙여요(예: 🟣 개인, 🔵 학교, 🟢 가족).
- **일정:** 모든 계정의 캘린더를 한 화면에 합쳐서 보여 줘요. 색으로 어느 계정 일정인지 구분해요.
- **메일:** 모든 계정의 받은 편지를 합쳐서 요약해요. 계정 이름표가 붙어요.
- **넣기·보내기:** 일정을 넣거나 메일을 보낼 때 어느 계정으로 할지 **확인 카드에 꼭 보여 줘요.** 그래서 계정이 헷갈려 잘못 보내는 일을 막아요.
  - 계정마다 기본값을 정할 수 있어요(예: "학교 일은 학교 계정").
- 계정 연결 열쇠(구글이 주는 토큰)는 **서버에만, 잠가서(암호화) 보관해요.** 폰·PC 화면이나 GitHub에는 나오지 않아요. 계정마다 [연결 끊기]를 누르면 바로 지워요.
- 계정마다 권한을 고를 수 있어요: 캘린더만 / 메일 읽기만 / 메일 보내기까지.

- [x] Supabase: 커플 앱 프로젝트(couple) 안에 ai_ 칸 따로 (v0.2.0). 로그인은 일단 이메일+비밀번호, 구글 로그인은 2단계에서 구글 연결과 함께

### 2단계 · 일정·메일·먼저 제안 (v0.3)
- [ ] 구글 계정 여러 개 연결·이름표·색·연결 끊기 (4-1 참고)
- [ ] 구글 캘린더 연결(모든 계정 합쳐 보기): 읽기 + (허락 후) 넣기·고치기

- [ ] 폰 알림 켜기

### 3단계 · PC 일꾼: 빈자리 알림 · 대신 누르기 (v0.4)

- [ ] 대신 누르기: 단계마다 화면 사진을 보내고, 중요한 버튼 앞에서 허락받기

## 6. 미리 알아 둘 함정
- **지메일 연결:** 구글이 메일 권한을 엄격하게 봐요. 개인용 "테스트 모드"로 두면 7일마다 다시 로그인해야 할 수 있어서 설정을 잘 해야 해요. 연결할 계정은 전부 구글 클라우드 "테스트 사용자"에 미리 적어야 해요.
- **학교·회사 구글 계정:** 학교(nyschool.co.kr)처럼 기관이 관리하는 계정은 관리자가 외부 앱 연결을 막아 둘 수 있어요. 막혀 있으면 그 계정은 빼고 나머지만 연결해요.
- **사이트 차단:** 코레일처럼 자동화를 막는 사이트가 있어요(피클도 막혔어요). 막히면 "직접 해 주세요"로 넘겨요.
- **무료 AI 한도:** Gemini 무료는 하루·1분 한도가 있어요. 그래서 가벼운 모델(flash-lite)을 기본으로 써요.
- **공개 저장소:** toy-store는 누구나 볼 수 있어요. 키·비밀번호·개인 데이터는 절대 코드에 넣지 않고, 서버 설정(환경 변수)에만 둬요.
- **개인정보:** 메일·일정 내용은 AI(구글 Gemini)로 보내져요. 학생 정보가 담긴 메일은 조심해요.
