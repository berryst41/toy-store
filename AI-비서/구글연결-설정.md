# 🔗 구글 연결 처음 한 번 설정하기

AI 비서 앱의 ⚙️ → **＋ 구글 계정 더하기** 버튼이 작동하려면, 구글에 "이 앱이 캘린더·메일을 써도 돼요"라는 **허가증(OAuth 클라이언트)**을 한 번 만들어야 해요. 한 번만 하면 그다음부터는 앱 안에서 계정을 몇 개든 더할 수 있어요.

## 1. 구글 클라우드에서 프로젝트 만들기
1. https://console.cloud.google.com 에 개인 구글 계정으로 들어가요.
2. 위쪽 프로젝트 고르기 → **새 프로젝트** → 이름 `AI 비서` → 만들기.

## 2. 쓸 기능 켜기
**API 및 서비스 → 라이브러리**에서 아래 두 개를 찾아 각각 **사용**을 눌러요.
- Google Calendar API
- Gmail API

## 3. 동의 화면 (Google 인증 플랫폼)
1. **API 및 서비스 → OAuth 동의 화면(Google 인증 플랫폼)** → 시작하기
2. 앱 이름 `AI 비서`, 지원 이메일은 내 메일 → 대상 **외부** → 연락처 이메일 → 만들기
3. **대상(Audience) → 테스트 사용자 → 사용자 추가**: 연결할 **구글 계정 이메일을 전부** 적어요 (개인, 가족 등 여러 개).
   - ⚠️ 여기 없는 계정은 연결이 안 돼요.
   - ⚠️ "테스트" 상태로 두면 구글이 **7일마다 연결을 끊을 수 있어요.** 그러면 앱에서 다시 [＋ 구글 계정 더하기]로 같은 계정을 연결하면 돼요. (나중에 "앱 게시"를 누르면 이 문제가 줄지만 "확인되지 않은 앱" 경고가 떠요 — 나만 쓰는 거라 경고에서 "고급 → 이동"을 누르면 돼요.)

## 4. 허가증(클라이언트) 만들기
1. **클라이언트(사용자 인증 정보) → 클라이언트 만들기 → 웹 애플리케이션**
2. 이름 `AI 비서 앱`
3. **승인된 리디렉션 URI**에 아래 주소를 **정확히** 넣어요:
   ```
   https://berryst41.github.io/toy-store/AI-%EB%B9%84%EC%84%9C/
   ```
4. 만들기 → **클라이언트 ID**와 **클라이언트 보안 비밀번호**가 나와요. (보안 비밀번호는 다른 사람에게 보여 주지 마세요.)

## 5. Supabase에 두 값 넣기
1. https://supabase.com/dashboard → 프로젝트 **couple** → **Edge Functions → Secrets(비밀)**
2. 아래 두 개를 추가해요:
   | 이름 | 값 |
   |---|---|
   | `GOOGLE_CLIENT_ID` | 4번의 클라이언트 ID |
   | `GOOGLE_CLIENT_SECRET` | 4번의 클라이언트 보안 비밀번호 |
3. 저장하면 끝이에요. (Claude에게 "구글 비밀값 넣는 창 띄워 줘"라고 해도 돼요 — 값은 Claude를 거치지 않고 Supabase 화면에서 직접 넣어요.)

## 6. 앱에서 연결하기
앱 → ⚙️ → 로그인 → 🔗 구글 계정 → 이름표·색·허락 범위 고르고 **＋ 구글 계정 더하기** → 계정 고르고 허락.
계정마다 반복하면 여러 개가 연결돼요.

## 학교 계정은?
학교·기관에서 관리하는 구글 계정은 관리자가 외부 앱 연결을 막아 둘 수 있어요. 막혀 있으면 "액세스 차단" 같은 화면이 나와요 — 그 계정은 빼고 쓰면 돼요.
