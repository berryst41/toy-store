## 2. PC 일꾼

웹 앱은 보안 때문에 다른 사이트를 누를 수 없어서, PC의 작은 프로그램(일꾼)이 브라우저 창을 따로 열고 대신 해요.

**하는 일**
- 빈자리 지켜보기: 주소와 찾을 글자("잔여", "예약 가능")를 주면 30초~5분마다 새로고침 → 나타나거나 "매진"이 사라지면 폰 알림.
- 대신 하기: AI가 화면을 보고 하나씩 누름 → 끝나면 "예약이 완료되었습니다" 같은 글자가 진짜 있는지 다시 확인.
- 대화로 맡기기: "이 링크 빈자리 나면 알려 줘".

**쓰는 방법**
1. 앱 ⚙️ → PC 일꾼 → [일꾼 받기]로 zip 받아 풀기.
2. `일꾼-켜기.bat` 더블클릭(처음 1~2분 준비, Node.js 없으면 설치 사이트가 열림).
3. 앱에서 [연결 코드 만들기] → 8글자를 검은 창에 입력.
4. 일꾼이 연 창에서 자주 쓰는 사이트에 한 번 로그인.
5. 다음부터는 bat 더블클릭만. 검은 창 닫으면 꺼짐.
6. (추천) `PC-켤때-자동켜기.bat`을 한 번 더블클릭 → PC를 켤 때 창 없이 저절로 켜져요(작업 표시줄에 안 보임). 끄기는 `자동켜기-끄기.bat`.
   - 학교 PC가 꺼져 있는 동안 폰에서 한 체크는, PC를 켜고 일꾼이 켜지면 20초 안에 쿨메신저 비서 창에도 들어가요.

**안전 규칙**
- 예약·결제·신청·보내기·삭제 버튼 앞에서 멈추고 화면 사진과 함께 허락 카드.
- 비밀번호·카드번호·인증번호는 절대 넣지 않고 서버에도 저장 안 함.
- 로그인 상태는 PC 안(`%LOCALAPPDATA%\AI비서일꾼`)에만.
- 자동화를 막는 사이트(일부 기차·공연 예매)는 안 될 수 있음 → "못 했어요"라고 알려 줌.

## 4. 쿨메신저 비서 데이터 가져오기 (v0.6.0 만듦 — 가짜 자료로 시험 통과, 진짜 학교 PC 시험은 아직)

**쓰는 방법:** 학교 PC에서 ① 쿨메신저 비서를 v0.2.4로 다시 설치(zip 받아 `1_설치하기.bat`) ② PC 일꾼도 새 zip(v0.6.0)으로 바꿔서 켜기. 그러면 20초 안에 앱 📅 일정 탭 아래 "📨 쿨메신저"에 나와요.
- 체크는 양쪽으로 맞춰져요(학교 PC 일꾼이 켜져 있을 때). 둘 다 동시에 바꾸면 앱 쪽이 이겨요.
- 대화로: "방과후 수요조사 끝냈어" → 체크, "브리핑 7시 반으로 바꿔 줘" → 브리핑 시각 바뀜.
- 집 PC 일꾼은 쿨메신저 비서가 없으니 이 일은 건너뛰고 예약·지켜보기만 해요.

쿨메신저 비서(school/cool-ai)가 **정리한 항목만** 앱으로 가져와요. 쪽지 원문은 안 올려요.
지금 정리된 항목: 88개(할 일 53, 적을 것 23, 기억할 것 12) — 2026-11-20 기준.

흐름:
1. 쿨메신저 비서가 쪽지를 정리해 `%LOCALAPPDATA%\CoolAI\items.json`에 저장(끝낸 건 `done.json`).
2. 같은 PC의 PC 일꾼이 1분마다 그 파일을 읽음.
3. 바뀐 항목만 서버(선생님만 보는 곳)에 올림.
4. 폰 앱의 쿨메신저 칸에서 봄 + AI 대화·아침 브리핑에서 참고.

| 올리는 것 | 안 올리는 것 |
| --- | --- |
| 종류(할 일/적을 것/기억할 것), 정리된 한 줄, 마감일, 보낸 사람, 받은 날, 즐겨찾기, 끝냈는지 | 쪽지 원문(msgs.json), 쿨메신저 비서의 키와 설정 |

- 쿨메신저 비서 프로그램은 안 고쳐도 됨.
- 조건: PC 일꾼이 쿨메신저 비서가 깔린 학교 PC에서 켜져 있어야 함.

**지금 상황**
- AI 딸기는 **구글 캘린더만** 읽어요. 폰의 삼성 캘린더에 "삼성 계정"이나 "내 폰"으로 저장한 일정은 못 봐요.
- 삼성은 다른 앱이 인터넷으로 삼성 캘린더를 읽는 통로(API)를 열어 두지 않았어요. 삼성 클라우드 웹에서도 캘린더를 볼 수 없어요.
- 대신 **안드로이드 폰 안에서는** 폰에 있는 모든 캘린더(삼성·구글·내 폰)를 한곳에서 읽을 수 있어요(안드로이드 "캘린더 저장소"). 단, **폰에 설치된 앱**만 할 수 있고, 웹앱(지금의 AI 딸기)은 못 해요.

**고를 수 있는 방법**

| | 방법 | 좋은 점 | 아쉬운 점 | 돈 |
| --- | --- | --- | --- | --- |
| A | 삼성 캘린더 일정을 **구글 캘린더로 옮기기**(새 일정은 구글에 저장하게 설정, 옛 일정은 수정 → 캘린더 바꾸기) | 지금 바로, 만들 것 없음. 폰·PC·AI 딸기 어디서나 같은 일정 | 손으로 옮겨야 함. 실수로 삼성에 저장할 수 있음 | 무료 |
| B | **"캘린더 다리" 작은 안드로이드 앱**(APK)을 만들어 폰에 설치 → 30분마다 폰의 모든 캘린더를 읽어 서버(`ai_` 칸)에 올림 → AI 딸기가 읽음 | 자동. 삼성·구글·내 폰 일정 모두. 읽기만 해서 안전 | 플레이스토어 밖 설치(직접 받은 APK 설치 허용 필요). 처음 만드는 데 시간. 안드로이드만 | 무료(GitHub에서 APK 만들기). 플레이스토어에 올리면 등록비 약 3만 원(25달러, 한 번) → 안 올려도 됨 |
| C | **AI 딸기 전체를 진짜 안드로이드 앱으로** 감싸기(Capacitor) + 캘린더 기능 | B의 장점 + 알림·위젯 등 폰 기능도 더 쓸 수 있음 | 일이 가장 큼. 업데이트할 때마다 APK 새로 설치해야 할 수 있음 | B와 같음 |
| D | **자동화 앱**(예: Automate, MacroDroid)으로 폰 캘린더를 읽어 서버로 보내기 | 앱을 만들 필요 없음 | 설정이 복잡하고, 무료판 제한·폰 절전에 막힐 수 있음. 될지 직접 확인 필요 | 앱마다 다름(무료판 제한 있음, 유료판은 쓰기 전에 꼭 물어보기) |
| E | 삼성 캘린더 ↔ **마이크로소프트(Outlook) 연동**이 되면 그쪽에서 읽기 | 서버에서 자동으로 읽음 | 지금 폰에서 이 연동이 되는지 **확인 필요**. 안 되면 못 씀 | 무료(확인 필요) |

**Claude 추천**
